# kabu-market · 大头菜市场

一个给聊天群用的炒菜小游戏，用的是虚拟金币：每天签到领一点金币，研究行情、低买高卖，把钱滚大；可以借钱加杠杆，也可以和群友直接交易。

玩家只需要几条 `/kabu` 命令。走势、新闻、杠杆、爆仓这些复杂的部分全部由后端处理。

*A chat-group market mini-game with virtual coins. Players type a few `/kabu` commands; the backend runs weekly hidden turnip trends, news-driven tomatoes, fat-tailed potatoes, per-group market impact, leverage with margin calls and player-to-player trades. Pure Python, no dependencies, no network.*

- 纯 Python 3.10+，没有第三方依赖，运行时不联网。
- 存储用 SQLite。也可以接入你自己 bot 的存储，只要提供 `db`、`transaction()`、`get`、`put` 这四样。
- 起源：作者和朋友的 QQ 群 bot 里的 `/kabu` 功能，这里单独拆出来开源。

## 先玩一下

```bash
python -m kabu_market            # 内存里玩，退出就清空
python -m kabu_market save.db    # 存档到文件
```

在本地终端里，可以直接输入群里会用的命令。另外还有几条只在本地试玩时可用的命令：`:user 名字` 切换玩家、`:@ 名字` 让下一句 @ 某人、`:wait 12h` 或 `:wait 3d` 快进时间、`:quit` 退出。

```
[player] /kabu sign
@player 欢迎来到大头菜市场！送你 100 金币当本钱。
签到成功，获得 12 金币，现在共有 112 金币，已连签 1 天。
[player] /kabu market
@player 本群下午的市场价格：
大头菜（d）：15.05 金币/个
西红柿（x）：30.51 金币/个
马铃薯（m）：种薯 2 金币/个，10月28日晚上 8 点收获
昨天的西红柿新闻：产区连日暴雨，西红柿减产
在本群买得越多价格越高，卖得越多价格越低。发 /kabu help 看各商品的脾气。
[player] /kabu plant 20
@player 种好了。想让别人不知道你种了多少，可以撤回刚才那条消息。10月28日晚上 8 点收获；停止播种的时间每期随机，在收获前 2 小时内。
[player] /kabu buy d 2
@player 花 31 金币买了 2 个大头菜，14 天后烂掉，剩 41 金币。本群现价涨到 15.11。
```

## 命令

| 命令 | 作用 |
| --- | --- |
| `/kabu` | 三行小卡片：你的金币、本群现价、常用命令 |
| `/kabu help` | 完整玩法说明 |
| `/kabu sign` | 签到：每天一次（所有群合计一次），领 10–15 金币；每连签满 7 天额外送 30；每周允许断一天；20% 概率附带一条小道消息（实际五真五假，但游戏里不告诉玩家） |
| `/kabu market` | 本群当前价格（上午、下午各一个），以及今天和昨天的西红柿新闻 |
| `/kabu bag` | 金币、欠款、净资产，以及你的全部存货 |
| `/kabu buy d 5`、`/kabu sell d 5` | 跟系统买卖大头菜（`d`）、西红柿（`x`）；数量可以写 `all` |
| `/kabu plant 10` | 种马铃薯（`m`），见下文「种土豆」 |
| `/kabu dump` | 把本群的存货一次卖光 |
| `/kabu loan 500`、`/kabu repay 500` | 加杠杆和还款 |
| `/kabu offer @群友 d 5 25` | 向群友报价（商品、数量、单价）；对方用 `/kabu ok 编号` 成交，自己可以 `/kabu cancel 编号` 撤回 |
| `/kabu rank` | 本群净资产前 10 |

命令全是短英文，在群里打完 `/kabu` 不用切中文输入法。中文写法（`签到`、`买 大头菜 5`……）也能用，作为别名保留。

## 规则

**钱包和货物**都跟着人走：一人一个钱包，所有群通用，第一次玩送 100 金币；在哪个群买的货，到别的群也能卖，卖出按所在群的价格算。

**三种商品，三种猜法**。每种商品的机制都不同，研究的方式也不同，但都没有能算出来的标准答案：

| 商品 | 基准价 | 价格怎么来 | 你在猜什么 |
| --- | --- | --- | --- |
| 大头菜 | 20 | 每周暗中定一种走势：波动、大冲高（最高可达 2–6 倍，比较少见）、一路跌或小冲高。下周是哪一种，按概率取决于上周；冲高从哪个时段开始也是随机的 | 这周是哪种走势。买入后 14 天会烂掉；买入价不低于本周日的价 |
| 西红柿 | 30 | 每天约 25% 概率出一条公开新闻，推着价格涨或跌；但涨跌幅度、哪天兑现都随机，还有三成概率「利好出尽」，价格往反方向走 | 这条新闻会怎么兑现 |
| 马铃薯 | 种薯 2 | 不在市场买卖，大家一起种，每 3 天统一收获，收获价由本群这期种的总数和玩的人数决定，各家地里收成不同 | 群友这期会种多少 |

**种土豆**：

马铃薯不在市场买卖，改成大家一起种、到点统一收获：

- `/kabu plant 10` 花 2 金币一个买种薯种下。每人每期最多种 100 个，只能在群里种。
- **每 3 天晚上 8 点收获**。你的收获价 = 2 × 1.8 × D ÷ (D + 本群这期种的总数) × 天气 × 你这块地的收成。
  - D 是「市场胃口」= 这期在本群玩过 `/kabu` 的人数 × 45，种不种都算。`/kabu market` 只用大白话显示「这期已有几人在本群玩」，不报公式里的数。以前 D 跟着种的个数涨，结果小额种植自己给自己补贴，拆成几个小号种还能多赚（外审算出同样 100 个，拆五个号从 −4 变成 +80），所以改了。
  - 天气全群一样，收成每家不同，两者平均都是 1，乘起来大约在 0.5–1.8 之间，收获那一刻才抽。所以同一期里有人赚有人亏：输的人看得到别人卖了多少，也知道下次少种一点、或者运气好一点就能赢。
- **种的人越多，每个卖得越便宜**，你自己多种也会压低你自己的价格（古诺竞争），所以没有「越多越好」，得猜群友这期会种多少。
- **这期一共种了多少，收获前谁都不知道**：bot 回 `plant` 时不报数，只提醒「想保密可以撤回刚才那条消息」。群友的命令是公开的，撤不撤回由他自己定，所以会有人放消息、有人打听。
- **停止播种的时间每期随机**，在收获前 2 小时内，事先不公布（蜡烛拍卖的做法），防止有人等到最后一刻看完别人的数再下手。
- 本期只有一个人种，就全额退款，防止一个人包场。
- 收获结果在你下次发 `/kabu` 时告诉你，包括本群这期每个卖价的最高和最低；`/kabu market` 只显示上一期本群一共种了多少、平均每个卖多少。
- 种下的土豆按本钱计入净资产，强制平仓卖不掉它们，收获时才结算。

数值按多人模拟定（`python tools/simulate_potato.py`：带钱包、按真实上限、收获四舍五入），目标是**好玩**而不只是平衡。每期人均收益与赢的期数：

| 群 | 结果 |
| --- | --- |
| 6 人混着玩（会猜、每次种 4 / 20 / 60 / 100、乱种） | 正常玩的基本打平（−0.6～−0.1），赢 35–44% 的期；每次种满 −1.2；乱种 −5.0 |
| 6 人都动脑猜 | +4.2，赢 54% |
| 6 人约好每人种 20 | +9.8，赢 76% |
| 6 人全乱种 | +1.0，赢 49% |
| 12 人混着玩 | 乱种 −3.1，每次种满 −3.2 |

同一期里有人赚有人亏的比例：6 人混玩 73%、12 人混玩 87%（全群同价时只有 12%）。D 取每人 45 而不是 50：到 50 时「每次种满 100」在混玩群里反而最赚（+4.9），贪心成了标准答案。

**其他规则**：

- **自然起伏**：三种商品的价格都叠加一层 GARCH(1,1)-t 噪声，参数取 10 只 A 股日线拟合结果的中位数（α 0.12、β 0.78、自由度 4.2）。效果是平时小幅波动，偶尔一个大跳，而且大波动会扎堆出现。
- **市场调节**：本群每买入一个，价格涨 0.2%；每卖出一个，价格退回一格（约跌 0.2%）；冲击每 6 小时回落一半。买和卖走同一条价格曲线，卖给系统时再少给 3%（系统差价），所以先买后卖、先卖后买，马上倒手都一定亏。各群的冲击分开计算，货物又跟着人走，所以可以跨群套利：在便宜的群买、去贵的群卖，做的人越多，价差越小。
- **贷款**：可以分多次借，欠款合计最多到净资产的 3 倍（4 倍杠杆），日息 1%，按天复利。净资产跌到欠款的 20% 以下会被强制平仓，任何人发 `/kabu` 都会触发检查；挂单里的货也算净资产，平仓时会被撤回一起卖掉。没还清的债，每次签到自动拿一半还，另一半留给你：手上没有存货就不会再被平仓。
- **群员交易**：单价必须在现价的 50%–200% 之间，卖方付 5% 手续费，这部分金币直接销毁。不提供转账。

## 接进你的 bot

```python
from kabu_market import Event, KabuMarket, Scope, Store

market = KabuMarket(Store("kabu.sqlite3"), clock)   # clock 只需要提供 now() -> 秒
if KabuMarket.matches(text):                         # 只认 /kabu 开头的消息
    reply = market.respond(Event(
        Scope(bot_id, "group", group_id), sender_id, text,
        sender_name=nickname, mentions=tuple(at_user_ids),
    ))
```

- `respond()` 返回一段要发回群里的文本，不会自己发消息。
- `KabuMarket.knowledge(event)` 返回本群规则、价格、新闻和提问人的仓位，是只读的，不写任何数据。可以塞进 LLM 的提示词，让聊天 bot 也能聊这个游戏、给看法式的持仓建议。

## 数值依据

```bash
python tools/simulate.py           # 跑经济模拟：会研究的玩家 vs 乱买的玩家
python tools/fetch_kline.py data/kline.json      # 拉 10 只 A 股的日线（腾讯行情接口）
pip install numpy scipy arch && python tools/fit_kline.py data/kline.json   # 拟合 GARCH(1,1)-t
```

经济模拟的设定：每个群一个玩家，跑 16 周，不算贷款和连签奖励。结果如下（每次运行的数字会略有浮动）：

| 玩家 | 交易日均 |
| --- | --- |
| 会研究的（简单的民间策略） | 约 +10，其中大头菜约 +7、西红柿约 +3（种土豆另算，见下） |
| 乱买乱卖的 | 约 −6 |

签到日均约 12.5，加上连签奖励约 16。所以会研究的人靠交易，收入能接近翻倍；乱买的人会亏。

为什么大头菜买入价不低于周日价：每周日价格按基准重新起步，和周六价无关。外审发现，周六价跌到 14 以下时买、周日卖，几乎稳赚（模拟 3777 笔一笔没亏，日均 +14.7），又成了标准答案。加上这条后，同一个套路日均 −1.5、七成亏钱；周日进货的「会研究」玩家不受影响（日均 +9.6 不变）。代价是乱买的人亏得更多（日均 −0.8 → −6.2），所以市场里会写明「买入要 X（不低于本周日价）」，让人一眼看懂。

为什么大头菜 14 天才烂、大冲高又比较少见：模拟发现保质期一长，「买了就拿着等大冲高」几乎稳赚，就成了标准答案。现在这个组合下，这条路平均还能赚，但运气差的人会亏。

真实行情数据只用于离线拟合参数，不随仓库分发。
